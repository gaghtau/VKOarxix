# Готовность модулей

Статусы по «Дополнениям к ТЗ», п. 5: «Реализовано», «Частично», «Имитация/макет», «Предложено для следующего этапа».

|---|---|---|
| Главная: баннер, каталог, история в документах, выставки, филиалы, новости, полезное, соцсети, подвал | Реализовано | + памятная дата, опрос, публичная статистика, погода (Open-Meteo) |

| Электронный каталог: иерархия, поиск по 12 параметрам, фильтры, сортировка, пагинация, сброс | Реализовано | Фасеты с количеством, шифр в строке поиска, «Ничего не найдено» с подсказками |
| Карточка документа, просмотрщик (листание, масштаб, полноэкранный режим), копирование шифра, «поделиться», избранное | Реализовано | Избранное — в браузере, без регистрации |

| Справочная информация, читальный зал, FAQ по темам | Реализовано | |

| Платные услуги | Имитация/макет | Структура и постановление; цены не опубликованы — нет утверждённого прейскуранта |
| Нормативные акты, антикоррупция, госсимволы, полезные ссылки, конвертер на латиницу | Реализовано | Часть ссылок на «Әділет» — поисковые (помечено) |
| Календарь памятных дат | Реализовано | 2026 г., 42 даты, KZ/RU (EN — оригинал с уведомлением) |

| Большой архив памяти: коллекции, галерея, личности, хронология, историческая карта | Реализовано | Историческая карта визуально отделена от карты филиалов |
| Онлайн-выставки: экспонаты, увеличение, переходы, источники | Реализовано | 3 демо-выставки |
| Новости: категории, поиск, сортировка, связанные | Реализовано | Часть новостей — реальные (комплаенс, пост. № 142, календарь) |
| ИИ-помощник: 3 языка, источники, честное «нет данных», ограниченный доступ | Реализовано | Локальный движок (разбор запроса + синонимы + ранжирование), без передачи данных наружу |

| ИИ по историческим материалам: аннотация, даты, места, рекомендации | Реализовано | Помечено «сформировано автоматически» |
| ИИ для сотрудников: извлечение метаданных, дубликаты | Реализовано | Локальные правила |

## Условия проверки

Windows 11, Node.js 24, Chromium (встроенный браузер), 1400×900 и 375×812, светлая и тёмная темы.
БД: 89 записей каталога (10 фондов, 10 описей, 34 дела, 35 документов, из них 1 черновик), 28 цифровых копий, 14 подразделений.
