# Тестовые учётные записи (только демо-стенд)

Создаются автоматически при первом запуске (`server/db.js`). Пароль у всех демо-пользователей одинаковый
и задаётся переменной окружения `DEMO_PASSWORD` (по умолчанию `Arhiv#2026`).
На промышленном стенде эти записи удаляются, пароли выдаются индивидуально.

| Логин | Роль | Что показать на защите |
|---|---|---|
| `superadmin` | Главный администратор | Пользователи, роли, журнал действий, всё остальное |
| `siteadmin` | Администратор сайта | Публикации, филиалы, пользователи (кроме главного администратора) |
| `editor` | Редактор | Создание новости → черновик → «На проверку»; публикация только одобренного |
| `archivist` | Сотрудник архива | Каталог: создание записи (черновик), импорт CSV, ИИ-извлечение метаданных, OCR |
| `ridder` | Администратор филиала (Риддер) | Изменить контакты Риддера — ОК; Зайсана — 403 (включить «Проверка прав») |
| `moderator` | Модератор | Одобрение/возврат на доработку, открытие доступа к цифровой копии |
| `analyst` | Аналитик | Обзор, ИИ-рекомендации, экспорт открытых данных; журнал — 403 |

Защита: scrypt-хеш паролей, httpOnly-cookie `SameSite=Strict`, CSRF-токен, блокировка после 5 неудачных
попыток на 5 минут (по логину и IP), автоматический выход через 15 минут бездействия.
