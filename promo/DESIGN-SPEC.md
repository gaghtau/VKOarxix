# Промо-ролик «Госархив ВКО» — дизайн-спецификация

Режим: **автономное свободное творчество** (выбор пользователя «Свободно, решай сам»).
Скилл: video-shotcraft. Язык титров: русский. 1920×1080, 30 к/с.

## Этап 0. Продуктовый бриф

- **Что это:** информационный сайт Государственного архива Восточно-Казахстанской области
  (прототип для Code Masters Hackathon 9.0, защита 13.11.2026). Без заявок и оплаты.
- **Для кого ролик:** жюри хакатона и посетители (от школьников до старшего поколения).
- **Главная мысль:** «Память края — открыта»: архив, который можно читать с телефона, без очередей.
- **Обязательные функции в кадре:**
  1. главная «Стол архивиста» (записки-разделы);
  2. «Большой архив памяти»: 39 личных фондов, поиск по имени;
  3. карточка личности со справкой и шифром фонда;
  4. «Тогда и сейчас» — Усть-Каменогорск 1891 / сегодня;
  5. карта филиалов с маршрутом по дорогам;
  6. прейскурант по постановлению № 289;
  7. финал с логотипом.
- **Решения по исполнению:**

| Требование | Решение |
|---|---|
| Длительность | 44,2 с (1325 кадров) — 6 функций и 3 паузы-титра |
| Звук | только SFX (без музыки), см. этап 6 |
| Данные | только публичные материалы сайта (фонды, справки, адреса, цены). Личных данных посетителей нет: комментарии и кабинет не снимаются |
| Анимации сайта при съёмке | выключены («Без анимации»), чтобы кадр был в итоговом состоянии |

## Этап 1. Визуальное направление

Рассмотрено три направления: (А) «Стол архивиста» — бумага, чернила, моно-подписи;
(Б) тёмный «киноархив» с плёночным зерном; (В) яркий «гос-портал» с синим.
**Выбрано А**: оно и есть дизайн-система сайта, ролик не должен надевать чужую «кожу» (принцип 2).
Styleframe пропущен осознанно: у сайта есть строгие токены (desk.css), и шаблон Ink Press,
от которого взяты сцены, уже в той же «бумажной» эстетике — достаточно перекраски.

**Токены (из public/css/desk.css):**
- бумага `#EFE8DA`, записка `#FBF8F1`, чернила `#151515`, приглушённый `#6A6458`;
- акцент — тёмно-зелёный `#1F3D2B` (метки филиалов, «Найти родственника»); сигнальный `#7CF29A`
  (индикатор монитора) — только для подсветок/швов;
- шрифты: заголовки **Onest 800**, подписи **JetBrains Mono** (капс, разрядка), интерфейс Inter;
- жёсткие тени-«оттиски», без скруглений крупнее 4–6 px у записок.

**Тон движения:** «спокойная институция» — между пресетами «Профессиональное доверие» и
«Спокойная забота»: вход ~24f, bezier(0.25,0,0.2,1), без лишних отскоков, кроме «посадки» на стол.

сайт показывает ту же пару. Смягчение — подписи «1891 · гравюра» / «сегодня · фото» и медленный проход.

## Этап 6. Звук
13 эффектов Freesound, все CC0 (public/audio/sfx/audio-manifest.json, FREESOUND-CREDITS.md);
два тихих файла усилены (+24/+19 дБ, лимитер), изменения записаны в манифест. Привязка пиков
с поправкой на задержку AAC 1,28f. Замер после рендера: посадка записки +0,1f, рывок шторки 0,0f,
удар финала −1,5f, посадка плашки маршрута +0,1f; пик дорожки −5,1 дБ. Музыки нет — одна версия.

## Этап 7. Независимая проверка
Первый прогон проверяющего (отдельный агент) — «не готово»: мелкие подписи поверх текста, титры
<0,6 с, бегущие блики в прейскуранте, края снимков в кадре, обрезанные аннотация и плашка,
дубли в финале, удар не на собранном логотипе, ФИО руководителя. Всё исправлено; повторно
проверено по кадрам 60–1300 и замером звука (см. out/qa/sheet-v4.jpg, final-check.jpg).

# Версия 2 — динамичный монтаж под музыку (заказчик: «скучно, добавь музыку»)

**Музыка:** «House Vibez» — Lily J, Mixkit Stock Music Free License (бесплатно, без указания автора,
коммерческое использование разрешено; файл из набора скилла `assets/audio/bgm/`).
Анализ (`analysis/beat_data.json`, `grid_drift.json`, скрипт `scripts/beat-librosa.py`, librosa по
references/music-beat-sync.md): **122.00 BPM**, t0 = 7.9356 с, T = 0.49180 с; сетка 1x: match 98.1 %,
средняя ошибка 6.8 мс, дрейф 1.4 мс, первая доля −6 мс от атаки — все пороги пройдены.
Структура: доли 48–80 плотно, 80–112 спад, **112 — «дроп»**, 112–176 плотно. Ролик начинается с доли 80.

**Линейка в долях** (кадр = round(beatT(n)·30), `beatT` учитывает обрезку трека и задержку AAC 1,28f):

| Доли | Кадры | Сцена | Приём / переназначение времени |
|---|---|---|---|
| 0–14 | 0–208 | логотип → стол | логотип 1:1 (≥30f покоя), дальше ×1,1 |
| 14–26 | 208–385 | колода → поиск | ×1,07 |
| 26–32 | 385–474 | справка | ×1,13 |
| 32–38 | 474–562 | **нарезка 2×2 на «дроп»** (новая сцена, карточка rhythm/quad-split-parallel-scenes) | с внутреннего кадра 8 1:1, рывок-наезд TR на долю 34 |
| 38–44 | 562–651 | титр «Как город изменился за 130 лет?» | слова за 1 с, фраза держится ≈1,5 с |
| 44–52 | 651–769 | тогда / сейчас | перелёт ручки на долю 45 |
| 52–60 | 769–887 | маршрут (с сильного удара доли 52) | посадка плашки на долю 59 |
| 60–68 | 887–1005 | прейскурант (с сильного удара доли 60) | ×1,19 |
| 68–78 | 1005–1152 | финал | логотип собран на долю 72, затем покой |

Итого 1152 кадра = 38,4 с (было 44,2 с). Убраны титры 1 и 3; добавлена нарезка (ИИ-помощник, доступность,
«Ищи. Читай. Приходи.», выставки). Вспышки на весь кадр — 3 (доли 14, 32, 52, интервалы ≥16 долей).

**Звук:** эффекты только для уникальных действий экрана (раздача, клавиатура, клики, маркер, посадки, удар
логотипа вместе с ударом музыки); «воздух» камеры и титров отдан музыке. Версия без музыки
(`--props=props-nobgm.json`) получает дополнительные взмахи камеры и нарастание к логотипу, эффекты +2,6 дБ.

**Проверка после рендера (§5b):** 12 склеек/акцентов против атак музыки в готовом файле — максимум 1,60 кадра
(посадка плашки), в среднем 0,37 кадра (норма ≤3, идеал ≤1,5); темп в рендере 122,02 BPM.
Пики: с музыкой −2,5 dBFS, без музыки −2,8 dBFS. Видео перекодировано в стандартный диапазон yuv420p
(Remotion выдавал yuvj420p); у версии без музыки звук перекодирован (−2 дБ), это сдвигает её на ≤1 кадр.

**Независимая проверка v2:** замечания — 4 вспышки, сжатые интервалы нарезки (<3f), мелкий текст в нарезке,
короткий титр, рамка скана гравюры, дубль «1,8 км», подпись поверх кнопок, тихая версия без музыки,
yuvj420p — исправлены и перепроверены по кадрам и замерам. Также найден и исправлен баг сайта:
в режиме «очень крупный текст» на мониторе было две кнопки «Открыть фото» (public/js/a11y.js).
