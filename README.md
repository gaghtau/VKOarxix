# Госархив ВКО — прототип нового сайта

Code Masters Hackathon 9.0 · кейс Государственного архива Восточно-Казахстанской области.
Защита — 13 ноября 2026 г.

Информационно-справочный сайт: электронный каталог «фонд → опись → дело → документ» с поиском
на обычном языке, просмотр разрешённых цифровых копий, онлайн-выставки, «Большой архив памяти»,
карта 14 подразделений с маршрутами, ИИ-помощник, три языка (KZ/RU/EN), светлая/тёмная тема
и административная панель с ролями, согласованием и журналом. **Заявления, заказы и оплата на сайте
не принимаются** — только сведения и ссылки на eGov.kz / e-Otinish.

## Запуск

Нужен Node.js ≥ 22.5 (используется встроенный SQLite `node:sqlite`). Других зависимостей, кроме Express и Leaflet, нет.

```bash
npm install
npm start          # http://localhost:3000/ru/   админ-панель: http://localhost:3000/admin
npm run reset      # пересоздать базу с демо-данными
```

Переменные окружения: `PORT` (3000), `PUBLIC_URL` (для sitemap/OG), `DEMO_PASSWORD` (пароль демо-пользователей).
Тестовые учётные записи — в [docs/TEST_ACCOUNTS.md](docs/TEST_ACCOUNTS.md).

## Дизайн

Палитра «два цвета + неожиданный акцент»: лесной зелёный `#1F3D2B` и песочный `#E8DCC4` делают 90 % работы,
электрический фиолетовый `#8B5CF6` / `#7C3AED` — только на главных действиях (поиск, «Электронный каталог»,
помощник). Шрифты: Lora (заголовки, архивная эстетика), Inter (текст), JetBrains Mono (шифры).
Обе темы — с контрастом по WCAG AA; есть режим «крупный шрифт» и «высокий контраст».

## Структура

```
server/
  index.js   — Express: публичный API, админ-API, SEO (meta, sitemap, robots, JSON-LD), безопасность
  db.js      — SQLite-схема и загрузка демо-данных
  seed.js    — данные: материалы заказчика + обезличенные демо-записи каталога
  auth.js    — scrypt, сессии, CSRF, блокировка входа, матрица прав, статусы публикации
  ai.js      — локальный «интеллектуальный» движок: разбор запроса, синонимы KZ/RU/EN, ранжирование,
               помощник, аннотации, извлечение метаданных, аналитика качества
  scan.js    — генератор демонстрационных «сканов» (SVG) с водяным знаком
  data/calendar.json — календарь памятных дат 2026 (из документа заказчика)
public/
  index.html, admin.html, css/, js/ (app, core, pages, catalog, memory, assistant, admin, i18n, icons)
  files/     — документы заказчика: постановление № 142, антикоррупционные материалы (RU/KZ)
materials/   — исходные материалы заказчика (ТЗ, дополнения, контакты, история, календари…)
tools/parse_calendar.py — разбор календаря памятных дат из .docx
docs/        — тестовые учётные записи, готовность модулей, сценарий защиты
```

## Что откуда

- **Реальные данные заказчика:** контакты, структура и руководители отделов, 13 филиалов (адреса, директора,
  телефоны, e-mail), история архива, календарь памятных дат 2026 (42 даты, KZ+RU), комплаенс-служба и PDF,
  постановление акимата № 142, социальные сети.
- **Демонстрационные данные (помечены «демо»):** 10 фондов, описи, дела и 34 документа каталога (обезличены),
  выставки, часть новостей. Цифровые копии — синтетические SVG с водяным знаком «ДЕМО-КОПИЯ».
- **Координаты филиалов** приблизительные (по населённому пункту) и помечены как требующие подтверждения.
- **Прейскурант** платных услуг не предоставлен — раздел показывает структуру и явно помечен как незаполненный.

## Проверка прав (сценарии из «Дополнений к ТЗ»)

| Сценарий | Как проверить | Результат |
|---|---|---|
| Закрытый файл | `/api/files/<id restricted>/1` | 403, SVG «Доступ ограничен» |
| Неопубликованная запись | `/ru/catalog/89` (черновик) | «Материал недоступен», `noindex` |
| Ошибочный вход ×5 | `/admin` | блокировка 5 мин, событие в журнале |
| Чужой филиал | `ridder` → изменить Зайсан | 403 + запись `denied` в журнале |
| Обход CSRF | запрос без `X-CSRF-Token` | 403 |
| Сотрудник открывает копию | `archivist` → file_status=public | 403, только модератор |
| Редактор публикует каталог | `editor` → approved→published | 403 |
| Импорт с ошибками | «Вставить пример» в Импорте | 1 строка импортирована, 4 — в протоколе ошибок |
| ИИ без данных | «Метрические книги 1910 года» | честное «не найдено», без выдуманных шифров |
| ИИ и закрытые данные | «Личные дела работников облисполкома» | только описание, копия не выдаётся |
| Недоступна карта/погода | отключить сеть | текстовые адреса и ссылки на маршрут остаются |

Готовность модулей — в [docs/READINESS.md](docs/READINESS.md).
