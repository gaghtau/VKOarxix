# Госархив ВКО — прототип нового сайта

Code Masters Hackathon 9.0 · кейс Государственного архива Восточно-Казахстанской области.
Защита — 13 ноября 2026 г.

Информационно-справочный сайт: электронный каталог «фонд → опись → дело → документ» с поиском
на обычном языке, просмотр разрешённых цифровых копий, онлайн-выставки, «Большой архив памяти»,
карта 14 подразделений с маршрутами, ИИ-помощник, три языка (KZ/RU/EN), светлая/тёмная тема
и административная панель с ролями, согласованием и журналом. **Заявления, заказы и оплата на сайте
не принимаются** — только сведения и ссылки на eGov.kz / e-Otinish.

## Запуск

Нужен Node.js ≥ 22.5 (используется встроенный SQLite `node:sqlite`). Зависимости — Express, Leaflet и GSAP; при первом включении они ставятся сами.

**Включить и выключить одной командой** (сайт работает в фоне, терминал можно закрыть):

| Действие | Windows (PowerShell в папке проекта) | Любая ОС |
|---|---|---|
| Включить | `.\on` | `npm run on` |
| Выключить | `.\off` | `npm run off` |
| Перезапустить после правок | `.\restart` | `npm run restart` |
| Работает ли сейчас | `.\status` | `npm run status` |
| Журнал сервера | `.\logs` | `npm run logs` |

Сайт: http://localhost:3000/ru/ · кабинет редактора: http://localhost:3000/cabinet · журнал: `.run/server.log`.

Запуск в текущем окне (останавливается по Ctrl+C):

```bash
npm start          # http://localhost:3000/ru/   админ-панель: http://localhost:3000/admin
npm run reset      # пересоздать базу с демо-данными
```

Переменные окружения: `PORT` (3000), `PUBLIC_URL` (для sitemap/OG), `DEMO_PASSWORD` (пароль демо-пользователей).
Тестовые учётные записи — в [docs/TEST_ACCOUNTS.md](docs/TEST_ACCOUNTS.md).

## Палитра

Палитра «два цвета + неожиданный акцент»: лесной зелёный `#1F3D2B` и песочный `#E8DCC4` делают 90 % работы,
электрический фиолетовый `#8B5CF6` / `#7C3AED` — только на главных действиях (поиск, «Электронный каталог»,
помощник). Шрифты: Lora (заголовки, архивная эстетика), Inter (текст), JetBrains Mono (шифры).
Обе темы — с контрастом по WCAG AA; есть режим «крупный шрифт» и «высокий контраст».

## Что откуда

- **Реальные данные заказчика:** контакты, структура и руководители отделов, 13 филиалов (адреса, директора,
  телефоны, e-mail), история архива, календарь памятных дат 2026 (42 даты, KZ+RU), комплаенс-служба и PDF,
  постановление акимата № 142, социальные сети.
- **Реальные данные с действующего сайта e-arhiv.vko.gov.kz** (собраны с разрешения команды, ссылка на источник —
  в каждой карточке): 77 личных фондов архива с настоящими шифрами (ГАВКО, ф./оп.), объёмом и крайними датами,
  биографические описания, 44 фотографии из фондов; фото здания, читального зала, хранилища, выставок, сотрудников,
  официальные изображения госсимволов. Обработка: `tools/build_media.py` → `public/img/site` и `storage/catalog`.
- **Открытые источники:** 22 изображения из Wikimedia Commons (гравюра Усть-Каменогорска 1891 г., карта линии 1768 г.,
  фото Зайсанского поста 1875 г., ГЭС, виды городов) с автором и лицензией в подписи и на странице «Источники изображений».
- **Демонстрационные данные (помечены «демо»):** несколько условных фондов учреждений с описаниями без копий
  (для сценариев «ограниченный доступ», «требует проверки»), часть новостей, тестовые комментарии.
- **Координаты филиалов** приблизительные; **прейскурант** не предоставлен — раздел помечен как незаполненный.
- Цифровые копии каталога хранятся вне публичной папки и выдаются только через `/api/files` с проверкой доступа.

## Два режима: читатель и редактор

- **Читатель** — без регистрации, все функции сайта доступны сразу.
- **Редактор** — кнопка «Войти» справа вверху открывает отдельное окно `/cabinet` (логин `кана`, пароль `123123`;
  при неверном пароле вход не выполняется). В кабинете три вкладки:
  - **Комментарии** — все комментарии посетителей в одном списке; новые приходят уведомлением (счётчик на колокольчике,
    в заголовке вкладки, всплывающее сообщение и, по желанию, системное уведомление браузера); опубликовать, ответить, скрыть, удалить.
  - **Добавить на сайт** — новость или событие в хронологию, с фото (JPEG/PNG/WebP до 3 МБ, проверка содержимого файла);
    публикуется сразу.
  - **Мои публикации** — снять материал с сайта.
- Полная админ-панель для остальных ролей по-прежнему на `/admin`.

## Доступность (для старшего поколения и людей с ограничениями)

Кнопка «Доступность» в верхней строке (на телефоне — также в меню) открывает панель:

- **Размер текста:** обычный (16 px), крупный (20 px), очень крупный (24 px). В «очень крупном» режиме страница
  перестраивается в одну колонку, кнопки становятся выше, меню — в одну кнопку.
- **Фото на отдельной странице:** вместо мелких картинок — кнопка «Открыть фото»; фото открывается во весь экран
  с большими кнопками «Назад», «Крупнее», «Мельче». Включается автоматически вместе с «очень крупным» текстом.
- **Высокий контраст:** чёрное на белом, подчёркнутые ссылки, яркая рамка фокуса.
- **Удобное чтение** (новое): увеличенные интервалы между буквами и строками, без курсива и анимаций,
  жёлтая «линейка чтения» следует за пальцем или курсором — помогает при дислексии, СДВГ и усталости глаз.
- **Озвучивание** (новое): «Прочитать страницу вслух» с подсветкой читаемого абзаца, паузой, остановкой и выбором
  скорости; режим «Читать абзац по нажатию». Работает на устройстве (Web Speech API), текст никуда не отправляется.

Настройки сохраняются в браузере и применяются до отрисовки страницы (без мигания).

## Функции сверх кейса

- **«Как найти документы о родственнике»** (`/ru/family`) — три вопроса (что ищете, годы, где жил человек) →
  памятка: в какой архив/филиал обратиться (адрес, телефон, часы, маршрут), что делать по шагам, ссылка в каталог
  с фильтрами, кнопка «Распечатать памятку». Это не заявление: данные никуда не отправляются.
- **«Тогда и сейчас»** (`/ru/then-and-now`) — шторка-сравнение: Усть-Каменогорск 1891 и сегодня, здания архива
  до и после 1991 года, Зайсанский пост 1875 и озеро Зайсан. Работает пальцем, мышью и клавиатурой.
- **«Как сослаться на документ»** — в каждой карточке каталога готовая библиографическая ссылка (по образцу
  ГОСТ Р 7.0.100) с копированием и печатью карточки — для исследователей и студентов.

## Дизайн

Редакционный стиль «архивной описи»: бумажный фон, чернильно-зелёный текст, линейки и пронумерованные разделы,
моноширинные шифры; фиолетовый — только на главном действии. Стили — `public/css/redesign.css` и `public/css/catalogue.css` поверх `style.css`: поиск оформлен как ящик каталога с латунной табличкой и ручкой, разделы — закладками картотеки, переходы — каталожными карточками с линовкой и отверстием, портреты — фотокарточками в ящике; штамп архива на обложке, плавное появление блоков при прокрутке (отключается при «уменьшении движения» и в режиме «удобное чтение»).

## Комментарии посетителей

Под карточками каталога, выставками, новостями, коллекциями и страницами личностей. Премодерация: комментарий
появляется после одобрения модератором (роль «Модератор», «Редактор», администраторы) в разделе админ-панели
«Комментарии»; можно опубликовать ответ архива. Телефоны, e-mail и ИИН в тексте маскируются автоматически,
есть ограничение частоты и защита от ботов. Комментарий не является официальным обращением.

## Проверка прав (сценарии из «Дополнений к ТЗ»)

| Сценарий | Как проверить | Результат |
|---|---|---|
| Закрытый файл | `/api/files/<id restricted>/1` | 403, SVG «Доступ ограничен» |
| Неопубликованная запись | `/ru/catalog/89` (черновик) | «Материал недоступен», `noindex` |
| Ошибочный вход ×5 | `/admin` | блокировка 5 мин, событие в журнале |
| Чужой филиал | `ridder` → изменить Зайсан | 403 + запись `denied` в журнале |
| Обход CSRF | запрос без `X-CSRF-Token` | 403 |
| Сотрудник открывает копию | `archivist` → file_status=public | 403, только модератор |
| Редактор публикует каталог | `editor` → approved→published | 403 |
| Импорт с ошибками | «Вставить пример» в Импорте | 1 строка импортирована, 4 — в протоколе ошибок |
| Комментарий с телефоном | отправить «… 8 777 123 45 67» | текст сохранён как «[телефон скрыт]», на модерации |
| ИИ без данных | «Метрические книги 1910 года» | честное «не найдено», без выдуманных шифров |
| ИИ и закрытые данные | «Личные дела работников облисполкома» | только описание, копия не выдаётся |
| Недоступна карта/погода | отключить сеть | текстовые адреса и ссылки на маршрут остаются |

Готовность модулей — в [docs/READINESS.md](docs/READINESS.md).
